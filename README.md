# Portfolio — C#

A collection of small, self-contained .NET console projects demonstrating modern C#.

| Project | What it demonstrates | Run |
|---|---|---|
| [**Calculator**](Calculator/) | Recursive-descent parser, expression tree, polymorphism | `dotnet run` |
| [**ProblemSolving**](ProblemSolving/) | 11 classic algorithms + self-testing runner | `dotnet run` |
| [**NumberGuessing**](NumberGuessing/) | Game loop, adaptive bounds, input validation | `dotnet run` |
| [**PasswordGenerator**](PasswordGenerator/) | CSPRNG, rejection sampling, Fisher–Yates shuffle | `dotnet run` |

---

## 🛠️ Requirements

- .NET 8 SDK or newer

## 🚀 Run any project

```bash
cd Calculator        # or ProblemSolving / NumberGuessing / PasswordGenerator
dotnet run
```

---

## 🎯 Modern C# used across the projects

- Abstract / sealed classes & inheritance
- Pattern matching and `switch` expressions
- Tuples and deconstruction
- Range and index operators (`arr[..n]`)
- Local functions
- LINQ
- `System.Security.Cryptography` (`RandomNumberGenerator`)
- `Environment.Exit` for CI-friendly test results
